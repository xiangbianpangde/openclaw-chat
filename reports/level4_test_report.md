## LEVEL_4 测试方法

### LEVEL_4 断言函数

```python
async def assert_page_has_data(page, selector, error_messages=[]):
    """
    LEVEL_4 断言：页面有真实数据
    
    1. 检查元素存在
    2. 检查没有错误消息（暂无数据、加载失败等）
    3. 检查有真实数据（表格行数、列表项等）
    """
    # 1. 检查元素存在
    elements = await page.query_selector_all(selector)
    assert len(elements) > 0, f"应该有{selector}元素"
    
    # 2. 检查没有错误消息
    content = await page.content()
    default_errors = ['暂无数据', '加载失败', '错误', 'Error', 'Failed']
    for error in default_errors:
        assert error not in content, f"不应显示'{error}'"
    
    # 3. 检查有真实数据
    if 'table' in selector.lower():
        rows = await page.query_selector_all('table tr')
        assert len(rows) > 1, "表格应该有数据行（除了表头）"
```

### LEVEL_4 vs LEVEL_2 对比

| 标准 | 检查内容 | 示例 |
|------|---------|------|

| **LEVEL_4** ✅ | 检查真实数据 | `assert len(rows) > 1` 且 `assert '暂无数据' not in content` |
