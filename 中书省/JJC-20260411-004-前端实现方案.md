## 四、API 接口设计

### 4.1 REST API

#### 认证模块

| 方法 | 路径 | 描述 | 请求 | 响应 |
|------|------|------|------|------|
| POST | `/api/auth/login` | 用户登录 | `{username, password}` | `{token, user}` |
| POST | `/api/auth/logout` | 用户登出 | - | `{success}` |
| GET | `/api/auth/me` | 获取当前用户 | - | `{user}` |

#### 任务模块

| 方法 | 路径 | 描述 | 请求 | 响应 |
|------|------|------|------|------|
| GET | `/api/tasks` | 获取任务列表 | `?page=1&limit=10` | `{tasks, total}` |
| GET | `/api/tasks/:id` | 获取任务详情 | - | `{task}` |
| POST | `/api/tasks` | 创建任务 | `{type, params}` | `{task}` |
| POST | `/api/tasks/:id/execute` | 执行任务 | - | `{task_id}` |
| GET | `/api/tasks/:id/status` | 获取任务状态 | - | `{status, progress}` |
| GET | `/api/tasks/:id/result` | 获取任务结果 | - | `{result}` |

#### 知识库模块

| 方法 | 路径 | 描述 | 请求 | 响应 |
|------|------|------|------|------|
| GET | `/api/knowledge` | 获取知识库列表 | - | `{docs}` |
| POST | `/api/knowledge` | 添加文档 | `{title, content, category}` | `{doc}` |
| DELETE | `/api/knowledge/:id` | 删除文档 | - | `{success}` |
| GET | `/api/knowledge/search` | 搜索文档 | `?q=xxx` | `{results}` |

#### 查询模块

| 方法 | 路径 | 描述 | 请求 | 响应 |
|------|------|------|------|------|
| POST | `/api/query` | 执行查询 | `{query}` | `{result, intents}` |
| POST | `/api/query/intent` | 意图识别 | `{query}` | `{intents}` |
| POST | `/api/query/attribution` | 归因分析 | `{stock, metric, period}` | `{result}` |

#### 日志模块

| 方法 | 路径 | 描述 | 请求 | 响应 |
|------|------|------|------|------|
| GET | `/api/logs` | 获取日志列表 | `?level=info&limit=100` | `{logs}` |
| GET | `/api/logs/task/:id` | 获取任务日志 | - | `{logs}` |

#### 配置模块

| 方法 | 路径 | 描述 | 请求 | 响应 |
|------|------|------|------|------|
| GET | `/api/config` | 获取配置 | - | `{config}` |
| PUT | `/api/config` | 更新配置 | `{config}` | `{success}` |

### 4.2 WebSocket

#### 连接端点

```
ws://localhost:8000/ws?token=<access_token>
```

#### 消息格式

**客户端→服务端:**
```json
{
  "type": "subscribe",
  "payload": {
    "channel": "task_progress",
    "task_id": "task_001"
  }
}
```

**服务端→客户端:**
```json
{
  "type": "task_progress",
  "payload": {
    "task_id": "task_001",
    "progress": 75,
    "status": "running",
    "message": "正在执行任务二..."
  }
}
```

#### 频道类型

| 频道 | 描述 |
|------|------|
| `task_progress` | 任务进度更新 |
| `task_complete` | 任务完成通知 |
| `system_alert` | 系统告警 |
| `log_stream` | 日志实时流 |

## 五、数据库 Schema 设计

### 5.1 用户表 (users)

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    email VARCHAR(100),
    role VARCHAR(20) DEFAULT 'user',  -- admin, user
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 5.2 任务表 (tasks)

```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_uuid VARCHAR(36) UNIQUE NOT NULL,
    task_type VARCHAR(50) NOT NULL,  -- task1, task2, task3
    status VARCHAR(20) DEFAULT 'pending',  -- pending, running, completed, failed
    params JSON,
    result JSON,
    progress INTEGER DEFAULT 0,
    created_by INTEGER REFERENCES users(id),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    started_at DATETIME,
    completed_at DATETIME
);
```

### 5.3 知识库文档表 (knowledge_docs)

```sql
CREATE TABLE knowledge_docs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    doc_id VARCHAR(36) UNIQUE NOT NULL,
    title VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    category VARCHAR(50),  -- 研报，财报，行业知识
    metadata JSON,
    embedding VECTOR(768),  -- 向量嵌入（可选）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 5.4 查询历史表 (query_history)

```sql
CREATE TABLE query_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    query_text TEXT NOT NULL,
    intents JSON,
    result JSON,
    user_id INTEGER REFERENCES users(id),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 5.5 系统日志表 (system_logs)

```sql
CREATE TABLE system_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    level VARCHAR(20),  -- debug, info, warning, error
    message TEXT NOT NULL,
    source VARCHAR(100),
    context JSON,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 5.6 系统配置表 (system_config)

```sql
CREATE TABLE system_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    key VARCHAR(100) UNIQUE NOT NULL,
    value TEXT,
    description TEXT,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
