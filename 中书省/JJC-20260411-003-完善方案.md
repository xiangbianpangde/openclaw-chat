### 3.2 功能实现

#### 模块一：知识库构建 (knowledge_base.py)

**功能:**
- 加载中药行业研报、财报知识
- 构建向量索引
- 支持语义检索

**技术栈:**
- chromadb (轻量向量数据库)
- sentence-transformers (文本嵌入)

**核心函数:**
```python
class KnowledgeBase:
    def __init__(self, db_path: str)
    def add_documents(self, docs: List[Dict])  # 添加文档
    def search(self, query: str, top_k: int = 5)  # 语义检索
    def save(self)  # 保存知识库
```

#### 模块二：多意图规划 (intent_planner.py)

**功能:**
- 识别用户问题中的多个意图
- 分解为可执行的子任务
- 按顺序或并行执行

**技术栈:**
- 规则匹配 + LLM 意图识别

**核心函数:**
```python
class IntentPlanner:
    def __init__(self, kb: KnowledgeBase)
    def parse_intent(self, query: str) -> List[Intent]  # 意图识别
    def plan(self, intents: List[Intent]) -> List[Task]  # 任务规划
    def execute(self, tasks: List[Task]) -> List[Result]  # 执行
```

#### 模块三：归因分析 (attribution.py)

**功能:**
- 分析财务指标变化原因
- 识别关键驱动因素
- 生成归因报告

**技术栈:**
- 规则引擎 + 统计分析

**核心函数:**
```python
class AttributionAnalyzer:
    def __init__(self, db_path: str)
    def analyze_change(self, stock: str, metric: str, period: str)  # 变化分析
    def identify_factors(self, stock: str, metric: str) -> List[Factor]  # 因素识别
    def generate_report(self, analysis: Dict) -> str  # 生成报告
```

### 3.3 入口脚本 (run_task3.py)

**功能:**
- 整合三个模块
- 提供命令行接口
- 演示功能使用

**命令行参数:**

