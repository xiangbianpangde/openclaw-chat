## 六、API Keys 配置指南

### 6.1 OpenAI API Key

**环境变量:** `OPENAI_API_KEY`

**配置文件:** `~/.openclaw/config.json`

```json
{
  "openai": {
    "apiKey": "sk-..."
  }
}
```

### 6.2 Google Gemini API Key

**环境变量:** `GEMINI_API_KEY`

**配置文件:** `~/.openclaw/config.json`

```json
{
  "gemini": {
    "apiKey": "..."
  }
}
```

### 6.3 ElevenLabs API Key

**环境变量:** `ELEVENLABS_API_KEY`

**配置文件:** `~/.openclaw/config.json`

```json
{

    "apiKey": "..."
  }
}
```
