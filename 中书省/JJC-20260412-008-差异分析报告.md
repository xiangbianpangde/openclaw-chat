## 三、问题根因分析

### 3.1 根因 1：测试方法问题 ❌

**尚书省测试方法:**
```python
# 使用 aiohttp 进行 HTTP 请求
async with session.get(f"{BASE_URL}{url}") as response:
    status = response.status
    html = await response.text()
    # 只检查 HTTP 状态码和 HTML 字符串
```

**问题分析:**
- ❌ 只检查 HTTP 200 状态码
- ❌ 只检查 HTML 中是否包含特定字符串
- ❌ **不执行 JavaScript**
- ❌ **不渲染页面内容**
- ❌ **不检查页面实际功能**

**皇上测试方法:**
- ✅ 真实浏览器访问
- ✅ 执行 JavaScript
- ✅ 渲染页面内容
- ✅ 检查页面实际功能

**结论:** 尚书省的测试方法无法检测空页面问题！

### 3.2 根因 2：内网/外网差异 ⚠️

**尚书省测试地址:** `http://localhost:3001`

**皇上访问地址:** Cloudflare Tunnel（外网）

**问题分析:**
- 内网和外网可能部署了不同版本
- 前端构建可能未同步
- 静态资源可能不一致

**验证:**
```bash

# 外网测试

```

## 四、解决方案

### 4.1 方案 1：使用 Playwright 真实浏览器测试

**测试脚本:**
```python
from playwright.async_api import async_playwright

async def test_page_real_browser(page, url):
    # 真实浏览器访问
    await page.goto(url, wait_until="networkidle")
    
    # 等待页面渲染
    await page.wait_for_timeout(2000)
    
    # 检查页面内容
    content = await page.content()
    assert len(content) > 1000, "页面内容为空"
    
    # 截图证据
    await page.screenshot(path=f"screenshots/{url.replace('/', '_')}.png")
```

**优势:**
- ✅ 真实浏览器环境
- ✅ 执行 JavaScript
- ✅ 渲染页面内容
- ✅ 可截图取证

### 4.2 方案 2：统一内网/外网测试

**措施:**
1. 确保内网和外网部署同一版本
2. 使用 Git 提交哈希验证版本一致性
3. 内网测试通过后，再外网验证

**验证脚本:**

**风险:** 恶意 Skills 可能窃取数据、执行恶意代码

**防护措施:**

1. **来源验证**
   - 只从官方 GitHub 仓库下载 Skills
   - 验证 Git 提交哈希
   - 检查作者信誉

2. **代码审查**
   - 审查 Skills 源代码
   - 检查是否有恶意代码
   - 检查权限请求

3. **沙箱执行**
   - 在沙箱环境中运行 Skills
   - 限制文件系统访问
   - 限制网络访问

4. **权限控制**
   - 最小权限原则
   - 明确权限范围
   - 定期审计权限
