### M6：补充缓存失效策略（TTL/手动刷新） ✅ P2 已完成

**门下省意见：**
> 建议补充"缓存失效策略"（TTL/手动刷新），避免缓存数据过期问题

**修改内容：**
- **新增 TTL（Time To Live）机制**：默认 3600 秒（1 小时）
- **新增 LRU 限流机制**：超出 90% 容量时删除最旧 10%
- **新增手动刷新接口**：`invalidate_cache(pattern)`

**缓存策略配置：**
```python
class CachedInference:
    def __init__(self, ttl_seconds=3600, max_size=1000):
        self.ttl = ttl_seconds  # TTL: 1 小时
        self.max_size = max_size  # 最大容量：1000 条
```

**手动刷新接口：**
```python
# 清空所有缓存
cache.invalidate_cache()

# 按模式刷新（支持通配符）
cache.invalidate_cache("*2024*")  # 刷新所有含 2024 的缓存
```

**修订位置：** 方案二.2.4 节（缓存机制）

**验收状态：** ✅ 已完成（TTL+LRU+ 手动刷新）
