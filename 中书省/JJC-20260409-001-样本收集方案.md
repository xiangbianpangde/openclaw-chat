## 三、方案一：网络下载可行性分析

### 3.1 免费公开渠道调研

#### 3.1.1 慧博投研资讯（www.hibor.com.cn）

**优势：**
- 研报资源丰富（覆盖主流券商）
- 支持关键词搜索
- 部分研报无需付费即可下载

**劣势：**
- 需注册账号（手机号验证）
- 每日下载限额（免费用户约 5-10 份/日）
- 部分深度报告需付费
- 反爬虫机制（IP 限制、验证码）

**可行性评估：**
- **技术可行性：** ⚠️ 中等（需绕过反爬）
- **法律合规性：** ⚠️ 灰色地带（用户协议禁止批量下载）
- **时间成本：** 高（人工下载约 2-3 分钟/份）
- **预计样本数：** 10-15 份/日（免费账号）

#### 3.1.2 东方财富研报中心（report.eastmoney.com）

**优势：**
- 研报分类清晰
- 支持按机构、行业筛选

**劣势：**
- 需登录
- 大部分报告需付费（VIP）
- 反爬虫严格

**可行性评估：**
- **技术可行性：** ❌ 低（付费墙限制）
- **预计样本数：** 3-5 份/日（免费用户）

#### 3.1.3 券商官网

**优势：**
- 官方发布，格式规范
- 完全免费

**劣势：**
- 需逐个网站访问
- 大多需注册
- 无统一入口

**可行性评估：**
- **技术可行性：** ⚠️ 中等（需访问多个网站）
- **预计样本数：** 5-8 份/日（人工收集）

## 四、方案二：替代样本方案评估（36 份财务报告）

### 4.1 财务报告与研报格式差异分析

| 维度 | 标准财报（36 份） | 行业研报（目标 20 份） | 差异影响 |
|------|-----------------|---------------------|---------|
| **结构** | 高度结构化（三张表） | 半结构化/非结构化 | ⭐⭐⭐ 大 |
| **表格** | 固定格式、固定指标 | 格式多样、指标不固定 | ⭐⭐⭐ 大 |
| **文字** | 少量附注 | 大量分析文字 | ⭐⭐⭐ 大 |
| **图表** | 少量 | 大量（柱状图、折线图） | ⭐⭐ 中 |
| **数据** | 历史数据 | 含预测数据、假设 | ⭐⭐ 中 |
| **长度** | 20-50 页 | 50-200 页 | ⭐ 小 |
| **排版** | 单栏为主 | 多栏常见 | ⭐⭐ 中 |
| **扫描版** | 较少 | 较常见 | ⭐⭐ 中 |

### 4.2 使用财务报告替代的可行性

#### 4.2.1 可测试的规则

| 规则类型 | 是否可用财报测试 | 说明 |
|---------|----------------|------|
| **OCR 识别** | ✅ 完全可用 | 扫描版 PDF 识别与内容类型无关 |
| **表格提取** | ✅ 部分可用 | 标准财报表格规则可测试，但无法测试复杂表格 |
| **元数据提取** | ❌ 不可用 | 财报无"投资评级"、"目标价"等字段 |
| **核心观点提取** | ❌ 不可用 | 财报无"核心观点"章节 |
| **多栏识别** | ⚠️ 有限可用 | 财报多为单栏，无法充分测试 |
| **跨页表格合并** | ✅ 可用 | 财报中也有跨页表格 |

#### 4.2.2 基线测试有效性评估

| 测试项 | 使用财报测试的有效性 | 说明 |
|--------|-------------------|------|
| **OCR 准确率** | ✅ 100% 有效 | 文字识别与内容类型无关 |
| **表格提取准确率** | ⚠️ 70% 有效 | 可测试标准表格，无法测试复杂表格 |
| **元数据提取准确率** | ❌ 0% 有效 | 字段完全不同 |
| **核心观点提取准确率** | ❌ 0% 有效 | 财报无此内容 |
| **综合准确率** | ⚠️ 约 50% 有效 | 仅 OCR 和部分表格测试有效 |

### 4.3 准确率验收标准调整建议

如使用财务报告替代，建议调整验收标准：

```python
        }
    
    def run_research_specific_tests(self):
        """研报专用规则测试（仅研报）"""
        metadata_results = []
        core_view_results = []
        
        for sample in self.research_reports:
            # 元数据提取测试
            meta_acc = test_metadata_accuracy(sample)
            metadata_results.append(meta_acc)
            
            # 核心观点提取测试
            view_f1 = test_core_view_f1(sample)
            core_view_results.append(view_f1)
        
        return {
            'metadata_accuracy': sum(metadata_results) / len(metadata_results),
            'core_view_f1': sum(core_view_results) / len(core_view_results)
        }
    
    def calculate_comprehensive_accuracy(self):
        """计算综合准确率"""
        general = self.run_general_tests()
        research = self.run_research_specific_tests()
        
        general_score = general['ocr_accuracy'] * 0.5 + general['table_accuracy'] * 0.5
        research_score = (
            research['metadata_accuracy'] * 0.4 +
            research['core_view_f1'] * 0.4 +
            0.2  # 多栏识别假设 100%
        )
        
        comprehensive = general_score * 0.6 + research_score * 0.4
        return comprehensive
```
