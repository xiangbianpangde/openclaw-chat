### 4.2 模板设计

**模板结构：**
```yaml
template:
  id: T001
  type: 单表查询
  pattern: "{公司} 的{指标} 是多少"
  sql_template: "SELECT {column} FROM {table} WHERE company_name = '{company}'"
  variables:
    公司：[茅台，五粮液，伊利，...]
    指标：[营收，净利润，毛利率，...]
    column: [revenue, net_profit, gross_margin]
    table: [income_statements]
  expected_count: 500 条
```

### 4.5 生成脚本

```python
# scripts/generate_synthetic_data.py
import random
import json

def generate_single_table_queries():
    templates = load_templates("single_table")
    companies = load_companies()
    metrics = load_metrics()
    
    for template in templates:
        for _ in range(1500):
            company = random.choice(companies)
            metric = random.choice(metrics)
            question = template["pattern"].format(公司=company, 指标=metric["name"])
            sql = template["sql_template"].format(
                column=metric["column"],
                table=metric["table"],
                company=company
            )
            yield {"question": question, "query": sql, ...}
```

### 5.4 标注规范

**问题标注规范：**
- ✅ 自然、口语化
- ✅ 包含必要实体（公司名、时间、指标）
- ❌ 避免歧义
- ❌ 避免过于复杂（>50 字）

**SQL 标注规范：**
- ✅ 符合 SQLite 语法
- ✅ 使用标准表名/字段名
- ✅ 添加必要注释
- ❌ 避免子查询嵌套>3 层
