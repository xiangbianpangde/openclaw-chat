```python
        """发送 CDP 命令"""
```

## 五、错误处理机制

### 5.1 错误分类

| 错误类型 | 描述 | 处理方式 |
|----------|------|----------|
| CDP 连接错误 | WebSocket 连接失败 | 重试连接，最多 3 次 |
| DOM 错误 | 元素未找到 | 记录错误，继续测试 |
| 截图错误 | 截图失败 | 记录错误，使用占位图 |
| 网络错误 | 请求超时/失败 | 记录错误，继续测试 |
| 脚本错误 | JavaScript 执行失败 | 捕获堆栈，记录日志 |
| 超时错误 | 操作超时 | 重试或跳过 |

### 5.2 错误捕获机制

```python
class ErrorHandler:
    """错误处理器"""
    
    def __init__(self):
        self.errors = []
        self.screenshots = []
        self.action_log = []
    
    def capture(self, error: Exception, context: dict) -> ErrorReport:
        """捕获错误"""
        report = ErrorReport(
            type=type(error).__name__,
            message=str(error),
            stack=traceback.format_exc(),
            context=context,
            timestamp=datetime.now().isoformat()
        )
        self.errors.append(report)
        return report
    
    def record_action(self, action: str, params: dict) -> None:
        """记录操作"""
        self.action_log.append({
            'action': action,

        })
```

### 5.3 重试机制

```python
class RetryHandler:
    """重试处理器"""
    
    def __init__(self, max_retries: int = 3, delay: float = 1.0):
        self.max_retries = max_retries
        self.delay = delay
    
    async def execute(self, func: callable, *args, **kwargs):
        """执行带重试的函数"""
        last_error = None
        for i in range(self.max_retries):
            try:
                return await func(*args, **kwargs)
            except Exception as e:
                last_error = e
                if i < self.max_retries - 1:
                    await asyncio.sleep(self.delay * (i + 1))
        raise last_error
```
