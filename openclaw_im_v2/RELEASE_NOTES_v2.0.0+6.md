# Release Notes v2.0.0+6

## 问题修复

### 登录页面无响应问题

**问题描述：**
- 输入 Token 和地址后点击登录没有反应
- 为空时会显示"不能为空"提示（验证逻辑正常）

**根本原因：**
1. 连接等待时间不足（原 500ms，不够建立连接）
2. 错误未传递到 UI（WebSocket 错误被捕获但没有显示）
3. 加载状态不明显（用户不知道正在连接）
4. Gateway 地址格式不明确（用户不知道是否需要端口）

**修复内容：**

### 1. 登录页面 (lib/screens/login_screen.dart)

✅ **添加连接测试**
- 登录前先测试服务器连接（5 秒超时）
- 连接失败时显示详细错误对话框

✅ **增强错误提示**
- 使用 AlertDialog 显示详细错误信息
- 错误信息包含具体原因和解决建议
- 支持文本选择，方便复制错误信息

✅ **明显加载状态**
- 登录按钮内显示白色 CircularProgressIndicator
- 按钮禁用状态清晰可见

✅ **地址格式提示**
- 输入框 hint 明确说明格式：`http://地址：端口`
- 使用说明中强调必须包含端口号（如 :7891）

### 2. 聊天页面 (lib/screens/chat_screen.dart)

✅ **连接状态指示器**
- 标题栏显示连接状态（绿=在线，红=失败，橙=连接中）
- 状态文字实时更新

✅ **连接中界面**
- 显示"正在连接服务器..."提示
- 明确告知用户最多等待 30 秒

✅ **连接失败界面**
- 显示详细错误信息
- 提供"重新连接"按钮
- 错误图标醒目提示

✅ **详细调试日志**
- 初始化和连接测试日志
- 历史消息加载日志
- 消息发送日志和错误堆栈

### 3. WebSocket 服务 (lib/services/openclaw_gateway_service.dart)

✅ **增加连接等待时间**
- 从 500ms 增加到 5 秒（等待 WebSocket 连接）
- 额外等待 2 秒接收 Gateway 响应
- 总等待时间最多 7 秒

✅ **详细错误回调**
- 连接错误时调用 onError 回调
- 错误信息包含具体原因和解决建议
- 区分连接时错误和运行时错误

✅ **调试日志**
- `[WebSocket]` 前缀标识所有 WebSocket 日志
- 记录连接 URL、原始地址、响应消息
- 记录连接成功/失败状态

### 4. OpenClaw 服务 (lib/services/openclaw_service.dart)

✅ **连接测试增强**
- 超时时间从 5 秒增加到 30 秒
- 测试 API 端点而非根路径
- 接受 200 和 401 状态码（401 表示服务器可达但需认证）

✅ **详细日志**
- 记录请求 URL 和响应状态码
- 记录超时和异常情况

## 技术改进

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| WebSocket 连接等待 | 500ms | 5 秒 + 2 秒响应等待 |
| HTTP 请求超时 | 无/5 秒 | 30 秒 |
| 连接测试 | 无 | 登录前测试 |
| 错误显示 | SnackBar | AlertDialog（可滚动、可选择） |
| 加载状态 | 按钮内小圆圈 | 按钮内圆圈 + 连接状态指示器 |
| 地址提示 | 简单示例 | 明确格式要求 |
