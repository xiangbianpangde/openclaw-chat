## 三、问题定位

**根本原因:** QueryResponse Pydantic 模型验证失败

**详细错误:**
```
pydantic_core._pydantic_core.ValidationError: 1 validation error for QueryResponse
result
  Input should be a valid dictionary [type=dict_type, input_value=[{...}], input_type=list]
```

**问题说明:**
- PLANNER.process_query() 返回 `results` 字段为列表
- QueryResponse 模型期望 `result` 字段为字典

---

## 四、修复方案

### 4.1 修改 QueryResponse 模型

```python
class QueryResponse(BaseModel):
    query: str
    intents: List[str]
    result: dict           # 单个结果（字典）
    results: Optional[List[dict]] = None  # 完整结果列表
    timestamp: str
```

### 4.2 修改 execute_query 函数

```python
@router.post("/", response_model=QueryResponse)
async def execute_query(request: QueryRequest):
    if PLANNER:
        planner_result = PLANNER.process_query(request.query)
        results = planner_result.get('results', [])
        return QueryResponse(
            query=planner_result['query'],
            intents=planner_result['intents'],
            result=results[0] if results else {"data": "无结果"},
            results=results,
            timestamp=datetime.now().isoformat()
        )
```
