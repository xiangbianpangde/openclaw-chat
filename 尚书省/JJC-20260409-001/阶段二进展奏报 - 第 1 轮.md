## 三、发现的问题

### 问题 1：表格提取性能瓶颈（P0）

**现象：**
- 第 1 次测试（无表格提取）：0.48 秒/文件
- 第 2 次测试（启用表格提取）：11.43 秒/文件

**原因：** PyMuPDF 的 `find_tables()` 性能较差

**影响：** 大文件（50MB+）解析可能超时

**解决方案：**
1. **方案 A：** 仅使用文本提取（快速模式）
2. **方案 B：** 表格提取异步化（后台处理）
3. **方案 C：** 使用 pdfplumber 直接打开 PDF（待测试）

---

### 问题 2：指标识别冲突（P0）

**现象：** 年份被误识别为指标值

**示例：**
```
营业收入：2025.0 vs 21.9  ← 2025 是年份，不应作为值
净利润：2022.0 vs 57937.45  ← 2022 是年份
```

**原因：** 指标识别规则过于宽松，未排除年份

**解决方案：**
1. 添加年份过滤（1900-2100 范围的值排除）
2. 增强上下文识别（"2023 年"作为时间状语）
3. 添加数值合理性检查

---

### 问题 3：核心指标缺失（P1）

**现象：** 部分文件提取指标数偏低（0-6 条）

**原因：**
1. 表格提取失败导致数据丢失
2. 文本提取规则不完善

**解决方案：**
1. 完善文本模式匹配
2. 添加多轮提取策略

## 四、已完成的改进

### ✅ 表格提取 API 修复

**修改前：**
```python
# 错误：pdfplumber 不支持 PyMuPDF Page 对象
with pdfplumber.open(page) as pdf:
    tables = pdf.pages[0].extract_tables()
```

**修改后：**
```python
# 正确：使用 PyMuPDF 原生 API
found_tables = page.find_tables()
for table in found_tables.tables:
    table_data = table.extract()
```

**结果：** 表格提取功能恢复正常，但性能下降 20 倍
