## 3️⃣ 技术问题与解决

### 3.1 PaddleOCR v3.x 兼容性问题

**问题：** PaddleOCR v3.4.0 存在 oneDNN 兼容性问题

**解决方案：** 降级到 PaddleOCR v2.9.1（稳定版）

**结果：** ✅ 解决，置信度 99.73%

### 3.2 网络研报下载受限

**问题：** 主流研报平台需登录/付费

**解决方案：** 使用本地 39 份样本 + 皇上亲自下载 5 份年报

**结果：** ✅ 解决，样本充足（44 份）

### 3.3 跨页表格样本不足

**问题：** 季报/半年报无跨页表格

**解决方案：** 皇上亲自下载 5 份年报（100+ 页）

**结果：** ✅ 解决，检测到 100% 跨页标记
