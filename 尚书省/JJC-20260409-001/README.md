# 泰迪杯 B 题：上市公司财报智能问数助手

**任务编号：** JJC-20260409-001  
**版本：** v0.1.0  
**状态：** 开发中  
**工期：** 15 周（75 人天）

---

## 项目概述

本项目为"泰迪杯 B 题"赛题解决方案，实现上市公司财报智能问数助手，支持：
- **任务一：** 财务数据库构建（100G 级 PDF 解析）
- **任务二：** 智能问数（NL2SQL 自然语言查询）
- **任务三：** RAG 增强（知识库检索 + 归因分析）
