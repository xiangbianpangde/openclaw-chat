## 🔍 问题分析

### 问题 1：表格提取失败（高优先级）

**现象：** 所有文件的表格提取均失败  
**错误信息：** `'Page' object has no attribute 'seek'`  
**原因：** pdfplumber 不支持 PyMuPDF 的 Page 对象  
**影响：** 无法从表格中提取财务数据，导致提取指标数偏低

**解决方案：**
```python
# 方案 1：使用 PyMuPDF 原生表格提取
tables = page.find_tables()

# 方案 2：将 PDF 保存为临时文件后用 pdfplumber 打开
# 方案 3：使用 pdfplumber 直接打开 PDF 文件
```

### 问题 2：指标识别冲突（中优先级）

**现象：** 校验器报告同一指标存在多个值  
**示例：**
- 营业收入：2025.0 vs 21.9（年份被误识别为指标值）
- 净利润：219.9 vs 23.5（不同期间的数据）

**原因：**
1. 指标识别规则过于宽松，将年份识别为数值
2. 未区分不同报告期（年报/季报）的数据

**解决方案：**
1. 增强指标识别规则，排除年份干扰
2. 添加报告期识别逻辑
3. 改进数值解析，过滤不合理值

### 问题 3：核心指标缺失（中优先级）

**现象：** 部分文件仅提取到少量指标  
**示例：** 某 4 页文件仅提取 6 条数据，缺失营业收入、总资产、净资产

**原因：**
1. 表格提取失败导致丢失大量数据
2. 文本提取规则不完善

**解决方案：**
1. 修复表格提取
2. 完善文本模式匹配规则
