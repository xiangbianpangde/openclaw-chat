## 🔧 归因实现

### 1. 溯源功能

```python
class AttributionTracker:
    def __init__(self):
        self.sources = []
    
    def add_sql_source(self, sql, table_names, row_count):
        """添加 SQL 数据源"""
        self.sources.append({
            'type': 'sql',
            'sql': sql,
            'tables': table_names,
            'rows': row_count,
            'confidence': self._calculate_sql_confidence(sql, row_count)
        })
    
    def add_document_source(self, doc_id, chunk_ids, relevance_scores):
        """添加文档数据源"""
        self.sources.append({
            'type': 'document',
            'doc_id': doc_id,
            'chunks': chunk_ids,
            'relevance': relevance_scores,
            'confidence': self._calculate_doc_confidence(relevance_scores)
        })
    
    def get_attribution(self):
        """获取归因信息"""
        return {
            'sources': self.sources,
            'overall_confidence': self._calculate_overall_confidence()
        }
    
    def _calculate_sql_confidence(self, sql, row_count):
        """计算 SQL 置信度"""
        # 基于查询复杂度、结果数量评估
        complexity = len(sql.split())
        if complexity < 10 and row_count > 0:
            return 0.95
        elif complexity < 20:
            return 0.85
        else:
            return 0.75
    
    def _calculate_doc_confidence(self, relevance_scores):
        """计算文档置信度"""
        if not relevance_scores:
            return 0.5
        return sum(relevance_scores) / len(relevance_scores)
    
    def _calculate_overall_confidence(self):
        """计算整体置信度"""
        if not self.sources:
            return 0.0
        confidences = [s['confidence'] for s in self.sources]
        return sum(confidences) / len(confidences)
```

### 2. 置信度评估

| 置信度 | 分数范围 | 说明 |
|--------|---------|------|
| **高** | 0.85-1.0 | 数据可靠，可直接使用 |
| **中** | 0.60-0.85 | 数据较可靠，建议核实 |
| **低** | 0.0-0.60 | 数据不可靠，需谨慎使用 |
