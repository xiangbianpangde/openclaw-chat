# 用户手册

**产品名称：** 财报智能问数助手  
**版本：** v1.0  
**日期：** 天启二年四月十三日（2026 年 4 月 13 日）

---

## 📖 产品简介

财报智能问数助手是一款基于 NL2SQL+RAG 技术的智能问答系统，支持：
- **自然语言查询**：直接用中文提问
- **财务数据查询**：营收、利润、资产等
- **行业分析**：对比、趋势、排名等
- **文档检索**：财报原文检索和归因

---

## 🚀 快速开始

### 1. 基本查询

**示例：**
```
用户：贵州茅台 2024 年的营业收入是多少？
助手：贵州茅台 2024 年的营业收入为 1234.56 亿元。[数据来源：财务数据库]
```

### 2. 对比查询

**示例：**
```
用户：对比贵州茅台和五粮液 2024 年的营收
助手：2024 年营收对比：
- 贵州茅台：1234.56 亿元
- 五粮液：987.65 亿元
贵州茅台营收更高。[数据来源：财务数据库]
```

### 3. 趋势查询

**示例：**
```
用户：贵州茅台近 5 年的营收趋势如何？
助手：贵州茅台近 5 年营收趋势：
- 2020 年：949.23 亿元
- 2021 年：1061.90 亿元
- 2022 年：1241.00 亿元
- 2023 年：1478.32 亿元
- 2024 年：1234.56 亿元
整体呈增长趋势。[数据来源：财务数据库]
```

### 4. 解释查询

**示例：**
```
用户：为什么贵州茅台的毛利率这么高？
助手：贵州茅台毛利率高的原因：
1. 品牌溢价：茅台是高端白酒代表品牌
2. 稀缺性：产能有限，供不应求
3. 成本控制：原材料成本相对稳定
[数据来源：行业研究报告]
```

## 📋 查询类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **事实查询** | 查询具体数值 | "贵州茅台 2024 年的营收是多少？" |
| **对比查询** | 多公司/多期对比 | "对比茅台和五粮液的营收" |
| **趋势查询** | 时间序列分析 | "茅台近 5 年的营收趋势" |
| **排名查询** | 排序/Top N | "营收最高的 5 家公司" |
| **解释查询** | 原因分析 | "为什么茅台毛利率高？" |

## ⚙️ 高级功能

### 1. 数据溯源

所有回答都标注数据来源：
- `[数据来源：财务数据库]` - 来自结构化数据
- `[数据来源：行业研究报告]` - 来自文档检索

### 2. 置信度显示

回答附带置信度：
- **高置信度**（>0.85）：数据可靠
- **中置信度**（0.60-0.85）：建议核实
- **低置信度**（<0.60）：需谨慎使用

### 3. 多轮对话

支持上下文理解：
```
用户：贵州茅台 2024 年的营收是多少？
助手：1234.56 亿元。
用户：那净利润呢？
助手：贵州茅台 2024 年的净利润为 623.45 亿元。
```
