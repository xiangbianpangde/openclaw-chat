## 📖 技术架构概述

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                      用户层                              │
│  Web UI / API Client / Mobile App                        │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                    API 网关层                             │
│  FastAPI + Uvicorn (ASGI)                               │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                  业务逻辑层                              │
│  - NL2SQL 引擎                                           │
│  - RAG 引擎                                              │
│  - 融合引擎                                              │
│  - 缓存层 (Redis)                                        │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                    数据层                                │
│  MySQL (结构化) + ChromaDB (向量) + MinIO (文档)        │
└─────────────────────────────────────────────────────────┘
```

---

### 1.2 核心模块

| 模块 | 职责 | 技术选型 |
|------|------|---------|
| **Web 框架** | API 服务 | FastAPI + Uvicorn |
| **NL2SQL 引擎** | 自然语言转 SQL | Qwen3.5-Plus |
| **RAG 引擎** | 文档检索 | ChromaDB + bge-large-zh |
| **融合引擎** | 结果融合 | 自定义融合策略 |
| **缓存层** | 查询缓存 | Redis |

### 1.3 API 接口设计

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/query` | POST | 自然语言查询 |
| `/api/v1/health` | GET | 健康检查 |
| `/api/v1/version` | GET | 版本信息 |
| `/api/v1/auth/login` | POST | 用户登录 |
| `/api/v1/docs` | GET | API 文档（Swagger） |
