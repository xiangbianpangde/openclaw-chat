## 🚀 快速部署

### 1. 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 必需 |
| Docker | 24.0+ | 容器化部署 |
| Redis | 7.0+ | 缓存 |

---

### 2. Docker 部署

**构建镜像：**
```bash
docker build -t caiwu-assistant .
```

**启动容器：**
```bash
docker run -d \
  --name caiwu-assistant \
  -p 8000:8000 \
  caiwu-assistant:latest
```

---

### 3. 验证部署

**健康检查：**
```bash
curl http://localhost:8000/api/v1/health
```

**预期响应：**
```json
{"status": "healthy", "version": "1.0.0"}
```
