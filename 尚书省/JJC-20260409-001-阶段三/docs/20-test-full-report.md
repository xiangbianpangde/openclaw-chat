## ⚠️ 错误案例分析

### 错误 1：Q15 - 净利润增长率计算

**查询：** "2024 年净利润增长率超过 20% 的公司有哪些？"

**预期 SQL：**
```sql
SELECT companies.name FROM financial_reports JOIN companies ON financial_reports.company_id = companies.company_id WHERE financial_reports.period = '2024'
```

**生成 SQL：**
```sql
SELECT c.name FROM companies c JOIN financial_reports fr ON c.company_id = fr.company_id WHERE fr.period = '2024' AND (fr.net_profit - LAG(fr.net_profit) OVER (PARTITION BY fr.company_id ORDER BY fr.period)) / LAG(fr.net_profit) OVER (PARTITION BY fr.company_id ORDER BY fr.period) > 0.2
```

**问题分析：**
- 生成 SQL 使用了窗口函数 LAG，过于复杂
- 实际应使用自 JOIN 或子查询计算增长率
- **EX 评估：** 生成 SQL 语法正确但逻辑复杂，可能无法正确执行
- **EM 评估：** 与预期 SQL 结构不同

**改进建议：**
- 增加增长率计算示例到 Few-shot
- 明确窗口函数使用场景

### 错误 2：Q10 - 上市日期查询

**查询：** "贵州茅台是什么时候上市的？"

**预期 SQL：**
```sql
SELECT listed_date FROM companies WHERE name = '贵州茅台'
```

**生成 SQL：**
```sql
SELECT listed_date FROM companies WHERE name = '贵州茅台'
```

**问题分析：**
- SQL 完全正确
- **EM 评估为❌是因为大小写差异**（listed_date vs Listed_Date）
- 实际应视为正确

**改进建议：**
- EM 评估应忽略大小写差异

### 错误 3：Q19 - 多期间对比

**查询：** "对比贵州茅台 2023 年和 2024 年的净利润"

**预期 SQL：**
```sql
SELECT period, net_profit FROM financial_reports JOIN companies ON financial_reports.company_id = companies.company_id WHERE companies.name = '贵州茅台' AND period IN ('2023', '2024')
```

**生成 SQL：**
```sql
SELECT fr.period, fr.net_profit FROM financial_reports fr JOIN companies c ON fr.company_id = c.company_id WHERE c.name = '贵州茅台' AND fr.period IN ('2023', '2024')
```

**问题分析：**
- 生成 SQL 使用了表别名（fr, c）
- **EM 评估为❌是因为表别名差异**
- 实际功能完全相同

**改进建议：**
- EM 评估应忽略表别名差异
