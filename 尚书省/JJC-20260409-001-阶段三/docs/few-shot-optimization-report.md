## 📋 优化方案

### 优化目标

1. **增加边界情况示例**（特殊字符、NULL 值）
2. **增加复杂查询比例**（GROUP BY、计算字段）
3. **保持示例简洁性**（每例≤100 字符）

### 新增示例（5 个）

#### 新增 1：特殊字符处理
```
问题：查询名称中包含"茅台"的公司
SQL：SELECT * FROM companies WHERE name LIKE '%茅台%'
说明：LIKE 模糊查询，处理特殊字符串
```

#### 新增 2：NULL 值处理
```
问题：查询没有 2024 年财报的公司
SQL：SELECT c.name FROM companies c WHERE c.company_id NOT IN (SELECT company_id FROM financial_reports WHERE period = '2024')
说明：NOT IN 子查询，处理缺失数据
```

#### 新增 3：多时间范围
```
问题：查询 2023-2024 年的财报数据
SQL：SELECT * FROM financial_reports WHERE period BETWEEN '2023' AND '2024'
说明：BETWEEN 时间范围查询
```

#### 新增 4：多表多条件
```
问题：查询白酒行业中 2024 年营收超过 500 亿的公司
SQL：SELECT c.name, fr.revenue FROM companies c JOIN financial_reports fr ON c.company_id = fr.company_id WHERE c.industry = '白酒' AND fr.period = '2024' AND fr.revenue > 50000000000
说明：多表 JOIN + 多条件过滤
```

#### 新增 5：复杂聚合
```
问题：查询各行业的公司数量和平均营收
SQL：SELECT c.industry, COUNT(*) as company_count, AVG(fr.revenue) as avg_revenue FROM companies c LEFT JOIN financial_reports fr ON c.company_id = fr.company_id GROUP BY c.industry
说明：LEFT JOIN + GROUP BY + 多聚合函数
```

## 📋 实施建议

### 1. 示例组织

**建议按难度分组：**
- **Level 1（1-10）：** 简单查询（单表/简单 JOIN）
- **Level 2（11-20）：** 复杂查询（聚合/排序）
- **Level 3（21-30）：** 边界情况（特殊字符/NULL/时间范围）

### 2. 使用策略

**根据用户查询复杂度动态选择示例数量：**
- 简单查询：使用 Level 1（10 个示例）
- 中等查询：使用 Level 1-2（20 个示例）
- 复杂查询：使用 Level 1-3（30 个示例）
