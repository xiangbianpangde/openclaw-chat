## 📊 改进建议

### 1. Few-shot 示例优化（已完成）

**优化内容：**
- 从 20 个增至 30 个示例
- 增加边界情况（特殊字符、NULL 值、时间范围）
- 增加复杂查询比例

**预期效果：**
- EX 准确率：95% → 97%
- EM 准确率：85% → 90%

### 2. EM 评估优化

**当前问题：**
- 大小写差异视为不匹配
- 表别名差异视为不匹配

**建议改进：**
```python
def normalize_sql(sql):
    sql = sql.upper()  # 统一大写
    sql = re.sub(r'\s+', ' ', sql)  # 规范化空格
    sql = re.sub(r'\s+AS\s+', ' ', sql)  # 移除 AS 关键字
    return sql.strip()
```

**预期效果：**
- EM 准确率：85% → 92%

### 3. 性能优化

**当前问题：**
- API 调用耗时约 30 秒/条
- 20 条测试需 10 分钟

**建议改进：**
- 批量调用（5 条/批）
- 异步调用
- 缓存重复查询

**预期效果：**
- 测试时间：10 分钟 → 3 分钟
