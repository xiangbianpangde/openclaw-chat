## 三、问题原因

**根本原因:** vite.config.js 缺少路径别名配置

**解决方案:** 添加 @ 别名指向 src 目录

---

## 四、修复操作

### 4.1 vite.config.js 配置

```javascript
import path from 'path'

export default defineConfig({
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src')
    }
  },
  // ...其他配置
})
```

### 4.2 安装依赖

```bash
npm install --save-dev @types/node
```

### 4.3 重启前端服务

```bash
npm run dev -- --host 0.0.0.0 --port 3001
```
