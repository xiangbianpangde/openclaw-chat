## 👑 奉天承运 太子制定

---

## 一、监督目的

为确保各部门工作效率，及时发现问题，特制定太子监督职责。

---

## 二、监督范围

**监督对象:**
1. 尚书省
2. 中书省
3. 门下省
4. 其他各部门

**监督事项:**
1. 任务进度
2. 汇报及时性
3. 工作质量
4. 问题处理

---

## 三、监督频率

### 3.1 定期检查

| 任务类型 | 检查频率 | 检查方式 |
|----------|---------|---------|
| **紧急任务** | 每 5 分钟 | 自动检查 |
| **普通任务** | 每 15 分钟 | 自动检查 |
| **长期任务** | 每 30 分钟 | 自动检查 |

### 3.2 不定期检查

**触发条件:**
1. 皇上临时旨意
2. 任务优先级变更
3. 发现异常情况
4. 收到举报

---

## 四、监督方式

### 4.1 自动监督

**工具:** `scripts/supervisor_check.py`

**功能:**
1. 定期检查任务进度
2. 检测汇报延迟
3. 发送催办通知
4. 记录延迟历史

**使用:**
```bash
# 启动监督服务
python3 scripts/supervisor_check.py --interval 15
```

### 4.2 人工监督

**监督方式:**
1. 查看看板状态
2. 检查 Git 提交
3. 审阅回奏文档
4. 听取部门汇报

### 4.3 混合监督

**流程:**
```
自动检测 → 发现问题 → 人工确认 → 发送催办 → 记录结果
   ↓           ↓           ↓           ↓           ↓
定时检查    延迟检测    核实情况    Telegram    累计次数
```

---

## 五、催办机制

### 5.1 催办等级

| 延迟时间 | 催办等级 | 催办方式 |
|---------|---------|---------|
| 5-10 分钟 | ⚠️ 轻度催办 | Telegram 通知 |
| 10-20 分钟 | ⚠️⚠️ 中度催办 | Telegram+ 看板标记 |
| 20-30 分钟 | ⚠️⚠️⚠️ 重度催办 | 直接质问 |
| >30 分钟 | 🚫 严重催办 | 上报皇上 |

### 5.2 催办流程

```
检测到延迟 → 发送催办 → 等待回复 → 超时处理
   ↓           ↓           ↓           ↓
超时检测    通知尚书省   10 分钟等待   上报皇上
```

### 5.3 催办模板

**轻度催办:**
```
【催办】任务 {task_id} 已延迟 {delay} 分钟，请立即汇报！
```

**中度催办:**
```
【严重催办】任务 {task_id} 已延迟 {delay} 分钟，尚书省需立即回奏！
```

**重度催办:**
```
【紧急催办】任务 {task_id} 已延迟 {delay} 分钟，尚书省立即回奏，否则上报皇上！
```

## 六、记录机制

### 6.1 监督记录

**记录内容:**
- 检查时间
- 任务状态
- 发现问题
- 催办记录
- 处理结果

**记录文件:** `太子/监督记录.md`

### 6.2 延迟统计

**统计维度:**
- 部门延迟次数
- 平均延迟时间
- 最长延迟时间
- 延迟趋势

**统计文件:** `太子/延迟统计.md`

### 6.3 月度报告

**报告内容:**
- 任务完成情况
- 延迟统计分析
- 问责执行情况
- 改进建议

**报告周期:** 每月一次

---

## 七、与皇上汇报

### 7.1 定期汇报

**汇报频率:** 每日一次

**汇报内容:**
- 当日任务完成情况
- 延迟统计
- 问责执行
- 异常情况

### 7.2 紧急汇报

**触发条件:**
1. 严重延迟（>30 分钟）
2. 重大失误
3. 系统故障
4. 皇上询问

**汇报方式:** 立即回奏
